Release notes ↗
Before installing +

The app is free to download; models retain their own licenses. Allow about 22 GB free for the default Sarvam installation, plus app space. Memory requirements vary by model and context. Quit Particle before updating; the installer preserves your models, chats and settings. The current tester build is ad-hoc signed and not Apple-notarized.

Local use and privacy +

Inference, conversations and optional memories stay on your Mac. Once a model is installed on a connected drive, local chat and file tools work offline. Downloads and updates use GitHub and Hugging Face; approved web tools contact external services. The website uses no analytics or tracking cookies.
