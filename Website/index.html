Experimental three-expert Sarvam profile, 2K context, short code task. Reduced experts can affect quality; speed varies by workload. Engine footprint excludes system and file-cache memory.

Measurement details +

Two naturally completed code responses measured 4.198 and 4.298 decode tokens/s, with 347 post-prefill steps each. The combined rate was 4.247 tokens/s. Decode timing includes reasoning and excludes model loading and prompt prefill.

The recorded peak sampled engine footprint was 1.79 GiB. A separate mixed-language test was slower and reached its reasoning limit without a final answer. These results do not establish the same speed or memory use for every task, longer context or other models. Six experts remains the native model profile.

Release notes ↗
Before installing +

The app is free to download; models retain their own licenses. Allow about 22 GB free for the default Sarvam installation, plus app space. Memory requirements vary by model and context. Quit Particle before updating; the installer preserves your models, chats and settings. The current tester build is ad-hoc signed and not Apple-notarized.

Local use and privacy +

Inference, conversations and optional memories stay on your Mac. Once a model is installed on a connected drive, local chat and file tools work offline. Downloads and updates use GitHub and Hugging Face; approved web tools contact external services. The website uses no analytics or tracking cookies.
