BEFORE YOU SETTLE IN

A few
good questions.

What kind of Mac do I need?

Particle is built for Apple silicon Macs running macOS 26 or newer. The original Sarvam setup was developed on an M2 with 8 GB of unified memory. Requirements vary by model, context length and expert cache. The app checks supported profiles; larger checkpoints may need more memory.

Is Particle free?

The app is free to download, and its source is on GitHub. Model downloads are separate and retain their original licenses. Local inference has no Particle subscription or per-token bill.

Does it work offline?

Chat and local coding actions can work offline after the app and a model are installed. Initial downloads, updates, web search and external tools need an internet connection. Keep your installed model on a drive that remains connected.

Which model should I start with?

Sarvam 30B is the default, powering Churo Chat and Churo Code. The other ten main models and three Fast models offer alternatives for Chat. You can adjust active experts for each model; reducing experts is experimental and may affect answer quality.

Can Particle Code change my files?

With a project selected and the required approval, Particle Code can read and edit files and run commands. Review changes and tool activity inside the app. The qualified coding workflow currently uses the default Sarvam model.

Will updating delete anything?

The installer updates the app while preserving your models, conversations, memories and settings. Quit Particle before running the update command. Older application releases are cleaned up after a verified installation.

Is the app Apple-notarized?

The current tester build is ad-hoc signed and is not Apple-notarized. The public installer verifies the release checksum and application identity. You can inspect the installer and the source on GitHub before running it.
